## Publicar na Vercel

Importe este repositório na Vercel. O arquivo `vercel.json` configura a instalação com `npm ci`, a compilação com `npm run build` e a pasta de saída `out`.

O portfólio é estático e não precisa de variáveis de ambiente, banco de dados ou serviços pagos.

## Desenvolvimento

Use Node.js 22.13 ou superior.

```sh
npm ci
npm run dev
```

Para validar a versão de publicação:

```sh
npm run build
```
